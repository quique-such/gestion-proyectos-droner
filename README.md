# Gestión de proyectos — DRÖNER

Dirección y planificación de DRÖNER, una startup ficticia de reparto de comida con drones, hecha con Microsoft Project.

![Gestión de proyectos — DRÖNER](docs/preview.jpg)

## Qué hace

- Caso de negocio, alcance y organización del proyecto.
- Estructura de descomposición del trabajo (EDT) y diagrama de Gantt.
- Asignación de recursos, presupuesto y análisis de riesgos.
