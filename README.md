# Gestión de proyectos — DRÖNER

Dirección y planificación integral de una startup ficticia de reparto de comida con drones (**DRÖNER**): estructura de descomposición del trabajo (EDT), diagrama de Gantt, asignación de recursos y duración de tareas, planificación económica (presupuestos) y análisis de riesgos. Realizado con **Microsoft Project**.

**Contenido:** `DRÖNER.pdf` (memoria), `DRÖNER.pptx` (presentación), `DRÖNER.mpp` (proyecto de MS Project).
